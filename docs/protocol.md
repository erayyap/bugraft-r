# Protocol and declared deviations

References read: full saved arXiv 2503.20036v2 paper and project site; paper III-A1, III-B1, III-B4, III-C3 and IV-A drive this protocol. Upstream source inspected only for crash observation, not planning/agent code.

- Dataset: all 86 issue.json files from the public **model** repository erayyapagci/bugcraft-dataset, pinned c7e08cfa23e2e39c254fcf9ec2fe0a2a45623fdb. Original JSON bytes remain unchanged under data/source; manifest includes hashes. No prior agent trajectories, generated steps, wiki, websites.json, or reproduction-package solutions enter Pi context.
- Inputs: public JSON contains final edited reports. Independently reconstruct the state immediately before the first history entry authored by [Helper], [Mod] or [Mojang], per paper III-B1. Reverse later summary/description/environment edits using exact fromString, undo individual affected-version additions/removals, and include only pre-cutoff comments. Original author steps are preserved verbatim. If an early comment was subsequently edited, its historic body is unavailable: exclude it and flag uncertainty, never invent replacement text. No trusted edit means retain supplied text and flag uncertainty. Incomplete changelogs fail closed. Audit records cutoff, original/input SHA-256, transformation hash and uncertainty per report. This deterministic interpretation may differ from unpublished author cutoffs; disclose in comparisons.
- Choose first reconstructed affected version, map display names to official Mojang version IDs, consult official version metadata for Java major requirement. Java 8/17/21 selected; Java 16 requirements run on 17 (documented compatibility default). Each attempt has a fresh Prism instance and world; only official download caches are reused. World seed is unspecified/random and recorded by game evidence when available.
- Required evaluated model: openai-codex/gpt-6-astra, thinking medium. Installed Pi 0.84.3 accepts explicit custom model ID because its clean built-in catalog does not list Astra; real provider requests succeeded, not a substitute model. No temperature override (Codex provider default); unlike original GPT-4o temperature=0 this is not a controlled identical sampling regime.
- Latest explicit user authorization permits exactly one generic computer-use extension and associated skill, with all auto-discovery disabled. Standard Pi builtins remain. --no-extensions plus explicit --extension; --no-skills plus explicit --skill is verified additive in installed Pi source/docs and actual inventory. No system-prompt replacement, injected solution context, hidden memories, or additional resources. Explicit /skill:computer-use expands only the approved generic UI skill. Fresh clean config/session/cwd for each case. Private auth is outside evidence.
- Budget: no assistant-turn cap; 20-minute wall-clock limit per case. One live-session `continue.` nudge is configured on the first terminal cybersecurity-risk flag, preserving the session/world and original deadline; repeated flags end provider_blocked. Errors and nudge events remain recorded, with no provider/filter switching. Setup/download time excluded from agent runtime, retained separately. Explicit model-controlled VM pause/resume is distinct from Minecraft's pause menu or tick freeze. Computer batches contain1–16 nonnested actions with at most30 seconds requested action time. All calls/actions/timing are retained.
- Guests: four Windows 10 Enterprise evaluation VMs, each8 GiB RAM and4 virtual CPUs, independent QCOW2 overlays backed by a cleanly stopped read-only source disk, KVM; not the paper's Windows 11/RTX4090 hardware. Mesa llvmpipe 26.2.0 OpenGL 4.6 software rendering, 6-chunk render distance, 30-fps cap. Software rendering and VM timing limit direct comparability, particularly hardware/timing-sensitive cases.
- Evidence: start/end/tool PNGs, complete Pi JSON event stream and sessions, 2-fps bounded H.264 video (300k target/500k max), model/tool/resource hashes, game latest.log, JVM stdout/stderr wrapper and fresh crash reports. Raw Prism authentication logs and auth screens excluded. Credentials transferred privately for legitimate account reuse and deleted from guest-shared transfer location after import. Host disk watchdog covers only our four VM containers at20 GiB free; cases refuse below25 GiB. No broad process kills or interference with other Docker workloads.
- Final plots use the disclosed user-directed convention of counting all observed crash/hang/reported-freeze candidates as successes. This does not replace the stricter raw detector labels or independently establish target identity.
- Strict target success requires the game crash **as described**, not a generic crash, process exit, stale attachment or report-ID occurrence. Fresh unmatched reports remain unrelated-or-unconfirmed until evaluator-only report-specific adjudication. Preserve actual crashes even at timeout. Setup blocks, harness errors, agent errors, evidence errors, ordinary exits and no-crash/timeout outcomes remain separate. Do not compute success over cases not run.
- Smoke gates: actual host and Windows main menus; real model-driven game interaction and exact inventory; then explicit mouse-look/inventory/input check. No official case starts before required gates pass. Resume skips only completed valid matching input/environment attempts and preserves earlier failed setup attempts.
